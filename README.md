# MUSE · AI 广告素材生成平台

一套面向广告投放运营团队的完整交互前端原型，覆盖从需求理解、智能选品、创意方案、单条预览、批量生成，到审核、素材入库和投放数据回流的全链路。

## 在线演示

[打开 MUSE 在线演示](https://muse-ai-creative-ops.yunzhixu620.chatgpt.site)

## 已实现模块

- 创意工作台
- 图片生成
- 视频生成与分镜编排
- 任务中心
- 审核管理
- 素材库
- 知识库
- 素材数据
- 用户、角色、模型与配额管理

图片和视频生成页采用五阶段流程：需求理解 → 智能选品 → 创意方案 → 单条预览 → 批量生成。页面包含 Agent 对话、结构化方案、任务状态、详情抽屉、审核操作、素材详情和数据看板等交互。

生成工作台支持直接点击流程步骤切换，并提供排队中、生成中、预览完成、批量生成、待审核、已完成和部分失败等可视状态。点击“状态演示”即可快速查看不同任务阶段及对应操作。

## 视觉设计

界面采用偏淘宝系的暖橙、红橙渐变与浅暖灰配色，并针对作品集展示统一增大了导航、正文、表格、标签和操作按钮字号。桌面端、平板和移动端均提供自适应布局。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建与验证：

```bash
npm run build
npm test
```

## 当前范围

当前仓库提供可交互的完整前端和模拟业务数据。真实模型调用、数据库、审核服务、素材存储和广告平台数据回流，可继续按照页面中的业务边界接入后端接口。
